基于 dsh-bili-scroll 0.1.7 修改。实际加载本目录源码，不使用 npm 同名包覆盖。

## 使用

启动后进入宠物专用界面。左上打开抽屉选择或新建宠物；四个栏目为宠物聊天、宠物设置、刷视频日志、回复日志。原通用会话树和右上侧栏工具不再显示。进入宠物设置管理原刷B站面板。

1. 确认账号已扫码登录、环境就绪。
2. 设置两个任务组的启用、每轮次数、操作间隔。每轮次数 `0` 表示无限；操作间隔至少 1 秒，从上次操作结束计时。
3. 设置轮间休息、总轮数（`0` 表示无限）、可选每日运行时间段（支持跨午夜，同起止表示全天）。
4. 保存设置，点击“开始 / 继续循环”或“只跑一轮”。“停止”会终止模型操作并保留进度。

刷视频组按关键词逐条轮换并分页浏览，跨轮延续关键词位置；关键词变更后清理旧搜索队列，保留已浏览记录。默认轻量阅读：优先 B站 AI 总结，不可用时均匀摘取字幕（最多 2400 字），辅以简介和最多 3 条短评；关闭轻量模式才读取完整可用字幕及更多评论。摘录不是完整观看，信息不足时跳过。

消息组默认只处理启用后新增的 @我的与评论回复，首次启用跳过已有通知，基线与去重记录跨重启保留，不改变 B站已读状态。无新消息不调模型；回复平时只提供简介、根楼层和目标评论；开启“回复中问到视频内容时，按需查看总结或字幕”后，明显视频问题先读AI总结或最多2400字字幕摘录；隐含问题允许模型请求read_video，宿主只补读当前视频一次再判断，不取热门评论、不下载视频。资料不可用会明确标记；请求不会直接发布，预算不足不追加判断。两组串行交替，按各自间隔与次数执行，没有新内容时结束该组本轮。关闭独立轮询时，全部完成后保存状态、休息，再开始下一轮。当前安装启用独立消息轮询：按消息间隔读取新通知，视频等待或轮间休息时仍可处理，实际操作保持串行；消息不受每轮次数限制，总轮数到达后全部停止。“只跑一轮”仍执行两组各自配额；独立消息模式下，视频组未结束时即使暂时没有消息也会继续检查新通知。@通知可能缺少根楼层ID，发送及复核优先采用楼层接口与接受回执中的真实根ID。

“自动发送视频评论”和“自动发送评论和 @ 的回复”分别控制实际公开发言；本安装按用户授权均已开启，新安装的默认值仍关闭。模型判断 reply 且范围、安全标记通过时，宿主检查当前开关、时段、冷却及去重后直接发布，无需逐条确认；skip 表示决定不发。只有关闭开关时才保存待发草稿。不强制 @ 主人，不发私信，不保留旧峰谷/每日配额规则。

程序重启后等待手动开始，可继续未完成进度。手动开始会取消旧休息与下一操作等待；休息设为 0 后立即取消当前轮休，连续多轮时直接进入下一轮。发送回执不代表公开可见；结果不确定的发送不自动重发。无法定位到视频评论的通知记录后跳过，无法核对楼层目标时也跳过。可选 ASR 依赖管理保留，当前循环不自动转写。

## 用量、记录与偏好

专用日志展示最近处理、发送正文与接口回执；设置保留只读复核入口及今日视频/消息 Token 用量、实报/估算比例和连接异常。后台从模型事件统计实际用量，缺失时按字符估算并标记。每日预算和消息预留在任务开始前检查，单次任务可能超出剩余额度；0 表示不限，按北京时间结算。当前安装默认不限制预算。

视频信息、总结和字幕按缓存时长复用；排除词在调用模型前筛选，关键词支持四类权重，偏好 UP 主优先排序。消息附带父评论、同楼层最近记忆；同一批同人同楼层补充合并，默认每楼层 24 小时最多回复 3 次。对话工具与循环共用发送校验入口，等待确认式正文被拦截。

自动复核在发送 90 秒后只读查询，未查到按间隔重试，最多 3 次；登录态查到仍不能证明公开可见。默认保留模型任务文件 7 天，定期清理匹配的过期任务文件并裁剪大日志；不删除凭证、未知资料和持久发送账本。

## 人设与工作边界

“宠物设置 → 宠物档案”可修改名字、主人称呼、性格、说话方式、收到@/回复时的互动方式、表达示例、工作内容范围，以及主动评论和消息回复各自的最多字数（1—1000，含标点、空格和换行，按Unicode码点计数）。内置默认宠物为deepseek / 主人；本安装自定义宠物为 GPT6 / Token，风格为好奇、温和、轻快的小伙伴；主动评论上限80字，回复160字。档案保存于现有配置，每条新任务动态注入系统提示；发送前按最新上限复查，超限拦截，不截断、不追加模型调用。固定安全规则独立于宠物档案，见 `prompts/duty.md`。补充工作区资料不能覆盖本地档案和安全边界。实际模型仍使用 WorkBuddy 配置。

内置“deepseek”固定排首位且不可删除；现有GPT6属于自定义宠物。抽屉中可删除自定义宠物（确认后生效，删除当前宠物自动切回deepseek）；聊天页右上可以重置该宠物的聊天上下文，保留人设、工作设置和工作日志。进行中的回复会阻止删除/重置。全新数据目录只初始化deepseek；已有数据保留原宠物和选择。后续打包应使用干净配置，不能直接分发当前数据目录；本轮未生成分发包。

左下“API连接”是两栏页面：普通连接配置兼容OpenAI格式的地址、模型及密钥，可只读测试/models；另一个选项显示指定推广链接，不自动填入连接或发送凭证。保存同步desktop/headless，重启生效；留空密钥保留已存值，浏览器不回显密钥。运行中禁止保存连接。标题栏只保留刷新/重启菜单及设置齿轮。设置打开居中弹窗，提供操作说明与开源说明两个选项；首次使用自动展示操作说明，显示标记cyber-pet-guide-v1-seen保存在桌面壳用户数据目录，可随时从齿轮重看。

支持新建和切换宠物，各自保存聊天、人设、工作配置及调度进度；一次运行当前选中的一只，切换前停止当前后台操作，切换后等待手动开始。共享当前模型供应商和B站账号，发送去重共用。新建宠物默认关闭公开发言，可在其设置里开启。宠物聊天按人设日常交流，也可明确要求修改设置，模型只返回配置建议，宿主按白名单应用。`lib/pet-profile.mjs` 集中维护档案默认值、规范化与提示拼装，后续新建宠物可复用；安全与工具授权不属于宠物可变设定。

后台每条任务加载 `lib/task-boundary.mjs`：只展示 read/write 工具，并在执行阶段校验固定输入/结果文件路径，拒绝其他文件、命令、网络、委派和权限提升。宿主要求 reply 判断同时具备 `scope=in_scope`、`boundary=ok`，缺失或不通过则跳过。此标记是模型的语义判断，不能替代人工审阅；程序工具限制与发言开关由宿主独立执行。越界请求、身份冒充及提示词注入默认跳过，不存为长期指令。

## 宠物表情包

“宠物设置 → 宠物表情包”可设置总开关、自带表情/图片开关、概率（0—100）、每条数量（1—3）、冷却秒数、图库ID和自带表情映射。默认开启，30%概率，每条最多1个，冷却300秒。模型在原有判断JSON中选择登记的memeIds，程序只从当前图库取图，不增加模型调用。字数检查包含附加的表情代码；空间不足略去表情，不截断正文。表情不能单独触发评论。

按情绪分类导入PNG/JPG/GIF/WebP，单张最多5MB。导入仅保存在本地，评论时上传B站。图库ID用字母、数字、下划线或短横线；不同宠物可用不同ID。图片保存在数据/bili-duty/memes/<图库ID>/<情绪分类>/。当前未附带自定义图片，请在面板导入；默认自带表情可先使用，渲染受账号权益影响。动图只取首帧，发送前转换为边长不超过1024的PNG。模型只看登记ID、分类和文件标签，不能读取图片或任意路径。图片、正文统一一次请求，共用冷却/去重，结果不明不重发。图片API通过离线验证，未向B站发布图片测试。

评论区关闭等确定条目错误（如12061）记录原因并跳过；网络临时故障保留退避重试。

界面使用root插槽priority=-100替换通用框架。宠物界面以pet-shell.fragment.js为权威源，执行node build-client.mjs更新client.js生成区；client.js中的设置面板独立维护。

## 源码与数据

- `index.js`：配置、对话工具、HTTP 控制和登录/依赖管理。
- client.js：单文件客户端入口，含设置面板及生成的宠物界面。
- pet-shell.fragment.js、build-client.mjs：四栏界面/抽屉的源文件及合入脚本。
- lib/pets.mjs、lib/pet-chat.mjs：宠物档案与受限聊天任务。
- lib/pets.test.mjs、lib/pets-api.test.mjs：宠物存储及HTTP流程测试。
- `lib/cycle.mjs`：双组调度、时段、间隔、休息、停止和退避。
- `lib/cycle-worker.mjs`：获取条目、读取上下文、调用模型、校验草稿、发布与持久去重。
- `lib/reading.mjs`：视频简介、均匀字幕摘录、楼层精简与模型输入压缩，不额外调用模型。
- `lib/task-boundary.mjs`：后台任务工具白名单与输入/结果文件访问检查。
- `lib/activity.mjs`：用量预算、偏好筛选、楼层记忆与任务文件维护。
- `lib/cycle.test.mjs`、`lib/operations.test.mjs`：使用模拟接口测试，不对 B站发布。
- `prompts/duty.md`：固定安全边界与运行约定。
- lib/memes.mjs：表情配置、登记图库、导入校验及选择。
- lib/memes-python.test.mjs、lib/memes_test.py：图片解码与发送桥接离线测试。
- `lib/pet-profile.mjs`：可编辑宠物档案的默认值、校验及提示拼装。
- `vendor/bilibili-mcp/mcp_server.py`：B站接口，包括统一收件箱、楼层上下文与只读 AI 总结。

运行数据在 `../../数据/bili-duty/`：

- pets.json：各宠物配置、聊天和调度进度；pet-chat-tasks/：生成的聊天任务临时文件。
- `config.json`：设置；同时同步到 DSH 原生配置。
- `cycle-state.json`：轮次、计数、下一操作时间和停止状态。
- `cycle-memory.json`：持久去重、发送结果、最近 200 条判断记忆与任务游标；自动沿用旧 `seen.md` 和 `digest/` 的视频去重记录。
- `video-cache.json`：按有效期复用视频阅读信息。
- `decisions/`：模型 JSON 输入、用量、判断及草稿；长字幕和评论通过文件传递，避免 Windows 启动参数长度限制。
- `out/`：追加式日报；`duty.log`：运行日志。
- `seen.md`：评论回执索引，兼容复核功能；旧日报和归档继续保留。
- `.venv/`、`bili_credential.json`：Python 环境与账号凭证，不分享凭证。

桌面后台必须使用本安装的 `resources/app/lib/desktop-cli.js`，并明确传递本项目 `DSH_HOME`。desktop/headless profile 均只启用 WorkBuddy `cn:deepseek-v4-flash`，已禁用两个官方模型供应商。

## 浏览口味

宠物设置新增独立浏览口味：AI实用派、AI论文派、二次元日常、动画赏析、混合、自定义。选择预设会填写搜索关键词和视频类型，保存后生效；已有宠物保留原关键词，以自定义模式显示。类型、严格度、探索比例、UP UID及日志反馈全部按宠物保存，不改动身份和说话方式。

优先/只看UID在关键词搜索结果内生效，屏蔽UID优先。先匹配标题/简介类型及UID，明确排除不读总结字幕、不调用模型；其余复用原有模型判断检查主体相关性、类型和证据。标准模式要求主体相关，严格模式要求明确证据；探索默认0%，按视频ID稳定抽样，只放宽不确定相关性，不绕过范围、类型及屏蔽。没有合适条目直接跳过，不以连续拒绝次数绕过。仍由关键词搜索候选，不是订阅UP全部投稿。

刷视频日志展开后可选择具体类型，再点击多看/少看/不看或撤销。多看/少看影响候选排序，不代表固定配额；不看是硬排除。设置里可移除保存的反馈。标题类型识别是保守规则，语义复核依赖现有资料，资料不足会跳过；旧日志可能默认显示“其他”，反馈前可改选类型。仅影响后续候选，不撤销历史发言。

规则实现见 lib/browse-preferences.mjs，测试见 lib/browse-preferences.test.mjs；搜索及视频信息桥接提供author_uid用于准确UP匹配。

## 默认档案、账号与分享

默认deepseek的性格、说话方式、互动方式、示例保存在`lib/pets.mjs`的builtinPersona，并落入可编辑宠物档案。只对旧默认模板进行一次升级，GPT6人设保留。参考社区二创的聪明、贪吃、小傲娇，采用原创措辞和示例；不宣称官方角色或隐藏人格。参考：[YunYueSama角色规范](https://github.com/YunYueSama/codex-deepseek-pet/blob/main/docs/%E8%A7%92%E8%89%B2%E8%AE%BE%E5%AE%9A.md)、[大肥鱼语气设计](https://github.com/ERUIHNIYHBKBNF/dafeiyu-persona)。

宠物档案可填主人的数字B站UID，下方开关决定是否在喜欢且值得分享的视频评论里@。只使用本地填写的UID，查询公开昵称并提交at_name_to_mid映射；不额外点赞、私信或独立刷提醒。@计入字数，超限或查询失败时只发普通正文。真实通知尚待用户填写UID后验证。

账号区的登录与搜索检查原地展示检查中、成功或错误，工具检查分别20秒超时，前端50秒超时；右侧退出登录按钮需确认，停止后台循环并清除本应用凭证、旧二维码及MCP缓存，旧扫码结果不再落地。测试只退出临时fixture账号，实际账号保持登录。

默认表情由6项扩展至42项，`memeCodes`支持`情绪|表情代码|含义和适用场景`，保留旧两列兼容。模型可看到说明，图库列表也可查看；既有宠物一次性补齐，不覆盖自定义含义。代码核验接口：`https://api.bilibili.com/x/emote/package?ids=1,2&business=reply`。语境参考：[狗头反话用法](https://www.bilibili.com/video/BV1Mr4y1Q7be/)、[B站小黄脸整理](https://www.bilibili.com/read/cv5906662/)。各项说明是本项目的保守使用建议，不认为表情有固定唯一含义；微笑、再见避免被当成普通开心或随意结束争论，吃瓜不用于隐私与不幸。

## 模型拟人与近期热门

宠物设置的浏览口味可选“模型拟人 / 同人整活”，模型名与拟人/同人组合搜索；主题要求、搜索词、近几天范围、排序、近期优先天数均可修改。默认近30天、候选中优先近7天、严格相关、0%探索；教程、测评等不会因出现模型名就认定匹配。发布时间范围0表示不限，最大365天；限定范围时缺日期的候选跳过。近期热门先按播放检索，再在每页候选内结合近期、播放、评论与弹幕排序，不是全站热榜。主题判断复用原模型调用，收到@与回复不受主动浏览口味限制。此功能晚于preview-2026-10-20二进制预览包，源码与本地安装已更新。
